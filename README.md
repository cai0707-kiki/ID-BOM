# ID-BOM — 海康机器人产品配单工具

> 面向海康机器人（Hikrobotics）工业视觉产品的 BOM（物料清单）在线配单系统，纯前端部署，打开即用。

## 功能特性

- **ID/SC双线配单** — 支持ID系列和SC系列相机的产品配单，分别独立配置
- **相机选型配单** — 选择相机型号后自动匹配电源、安装板、线缆、镜头罩、FA镜头、扩展配件等完整BOM
- **配件数据管理** — 内置配件数据库，支持按类别、系列筛选
- **BOM导出** — 一键导出配单结果为CSV
- **公告展示** — 主页可查看产品更新公告，内容与日期写在 `index.html` 的 `#announceConfig` JSON 块中
- **规格书速查** — 输入型号即可跳转海康机器人官网产品详情页
- **数据编辑器** — 独立的相机/配件数据管理界面，支持增删改查、搜索、CSV导入导出
- **快速搜索** — 全局搜索型号名称或物料代码，一键加入配单
- **ID/SC系列全览** — 按产品系列浏览全部相机和关联配件，支持快速搜索跳转并滚动定位到目标产品
- **ID/SC经销对照表** — 基线型号与经销型号映射查询，数据可在编辑器「🔗经销对照」Tab 维护
- **VM智能选型** — VisionMaster加密狗及软加密选型，覆盖读码、缺陷检测、定位测量、深度学习等8大应用场景
- **PDA选型** — 多维度筛选参数对比
- **线缆筛选** — 按长度和材质快速筛选线缆配件
- **图片预览** — 表格加载 80×80 缩略图，点击放大按需加载原图（无 Service Worker）
- **多端适配** — PC / PAD / 移动端响应式布局

## 快速开始

### 方式一：直接使用（推荐）

确保 `scripts/` 文件夹下的JS数据文件存在，直接用浏览器打开 `index.html` 即可使用，无需服务器或构建步骤。

### 方式二：更新数据

数据统一通过浏览器打开 `editor.html` 维护：

1. 顶部选择产品（🔵ID / 🟢SC / 🔐VM / 📰产品动态 / 🔗经销对照），点击「导入」载入对应 CSV（也可直接编辑现有数据）
2. 编辑、筛选、预览图片后，点击「导出JS」生成 `scripts/` 同名同格式的 JS 文件（如 `id_camera_data.js`）
3. 将导出的 JS 文件覆盖放入 `scripts/` 目录，刷新 `index.html` 即生效

### 数据流

**`scripts/*.js` 是唯一数据源。** `index.html` 只加载 JS，不读 CSV；`csv/` 是便于人工查看
和编辑器导入的副本，任何时候都可以由 JS 反向生成：

```
scripts/*.js（唯一真源）──→ index.html 运行时加载
      ↓ python tools/sync_csv_from_scripts.py
csv/*.csv（副本，供 editor.html 导入 / 人工查看）

editor.html 编辑 → 「导出CSV」或「导出JS」下载 → 手动覆盖 scripts/ 或 csv/ 下对应文件
```

改完 `scripts/*.js` 后如需要同步副本，运行：

```bash
python tools/sync_csv_from_scripts.py          # 重写 csv/
python tools/sync_csv_from_scripts.py --check  # 只比对差异，不写文件
```

> `tools/` 是本地维护脚本目录，**不纳入版本库**（已写入 `.gitignore`）。克隆仓库后如果
> 需要这些脚本，需另行获取；`csv/` 也是本地副本（`*.csv` 已被忽略）。
> 项目运行本身只依赖 `index.html` + `scripts/*.js` + `IMG/`。

## 数据编辑器

浏览器打开 `editor.html` 即可使用数据编辑器，支持：

- 顶部五选一切换：🔵ID产品 / 🟢SC产品 / 🔐VM产品 / 📰产品动态 / 🔗经销对照（ID/SC 按钮显示相机数据行数，VM/产品动态/经销对照显示各自行数；点击全局Tab提示「已切换至…」；VM、产品动态、经销对照为全局数据不分 ID/SC，选中时下方相机/配件子Tab条隐藏，点 ID/SC 自动回到相机子Tab）
- 相机数据 / 配件数据 子Tab切换（按导入文件名前缀 `id_`/`sc_` 自动切换产品；无前缀文件导入时弹窗询问归属）
- 搜索过滤（型号、物料代码、描述）+ 两级筛选：相机/配件按行对动态级联，VM、经销对照只保留单筛选（应用场景 / 产品系列），产品动态为固定选项（与主页一致）；有筛选时导出仍为全量数据并提示
- VM产品的「支持模块」「备注」两列按主页规则纵向合并单元格（有值行合并下方连续空行，仅渲染层效果，导出CSV/JS仍为逐行数据）
- 多行文本单元格按内容自动调整行高（合并单元格内的长文本完整显示，不会被截断）；产品动态「文档名称」列自动换行
- 单元格编辑、下拉选择、批量删除
- CSV导入 / 导出（相机/配件导出文件名带 `id_`/`sc_` 前缀；VM导出 `vm_dongle_data.csv`、产品动态导出 `product_updates.csv`、经销对照导出 `mapping.csv`，均为 UTF-8 带 BOM，可再次导入编辑器）
- JS导出（按当前产品+Tab 生成 `scripts/` 同格式同命名的 JS 文件，手动放入 `scripts/` 目录即可使用；VM/产品动态/经销对照导出为对象数组格式）——这是更新 `scripts/` 数据文件的唯一方式
- 图片缩略图预览（与主页一致）
- 修改结果自动保存到 localStorage 草稿（ID/SC 分开存储，旧版单套数据自动视为 ID）
- 页签/产品切换时自动保留当前页签的搜索与筛选状态（会话内存，刷新页面即清；导入 CSV 后重置，避免旧状态把新数据滤掉）
- 主页标题「智能产品线配单工具」三击可在新标签直接打开编辑器

> **保存（Ctrl+S）只写入浏览器 localStorage 草稿，不会写磁盘文件。** 编辑器是纯静态页面，
> 没有后端可写文件；要落到项目里，必须用「导出JS」下载后手动覆盖 `scripts/` 下对应文件。
> 清除浏览器数据会丢失草稿，请定期导出。

> 公告不通过编辑器维护（编辑器没有公告编辑功能）：公告内容与日期直接写在 `index.html`
> 的 `#announceConfig` JSON 块中（约第 1247 行）；主页版本号在同文件的 `V2.3.3` 文本处
> （约第 1241 行），数据更新日期由公告配置里的日期自动渲染到 `#dataUpdateDate`。

## 图片管理

图片按产品类型分目录存放，每个目录下有独立的THUMB缩略图子目录：

| 目录 | 用途 | 缩略图尺寸 | 数据来源 |
|------|------|-----------|----------|
| `IMG/ID_CAM/` | ID相机原图 | 80x80 | `id_camera_data.csv` |
| `IMG/ID_ACC/` | ID配件原图 | 80x80 | `id_accessory_data.csv` |
| `IMG/SC_CAM/` | SC相机原图 | 80x80 | `sc_camera_data.csv` |
| `IMG/SC_ACC/` | SC配件原图 | 80x80 | `sc_accessory_data.csv` |
| `IMG/PIC/` | QR码等 | 120x120 | 手动维护 |

### 图片加载机制

1. **表格显示** — `<img loading="lazy">` 加载 `THUMB/` 下的 80×80 缩略图
2. **点击放大** — 按需加载原图（`IMG/<目录>/<名称>.png`），不预加载
3. **加载失败** — `handleImageError` 最多重试 3 次（第 1 次退到原图，之后回落缩略图），
   全部失败后替换为 📷 占位符，仍可点击预览
4. **无 Service Worker** — 图片只依赖浏览器 HTTP 缓存，不做持久化离线缓存

### 缩略图生成

```bash
# 生成所有子目录缩略图
node resize.js --thumb

# 指定目录
node resize.js --thumb --dir ./IMG
```

### 图片尺寸调整（自动分发）

```bash
# 调整图片尺寸并自动分发到对应子目录
node resize.js -i ./OLD -o ./IMG -W 360 -H 360

# 覆盖已存在文件
node resize.js -i ./OLD -o ./IMG -W 360 -H 360 -f
```

图片会根据文件名自动匹配数据，分发到对应的 `ID_CAM/ID_ACC/SC_CAM/SC_ACC/PIC/` 目录。

## 规格书映射

`scripts/spec-mapping.js` 提供产品型号到海康机器人官网详情页的URL映射：

```javascript
// 获取型号对应的规格书/产品页链接
var url = getSpecUrl('MV-ID2013EM-05-RBN');
// → "https://www.hikrobotics.com/cn/machinevision/productdetail/?id=8379"
```

新增产品型号时，运行 `python search-spec-url.py` 自动从海康官网抓取并更新映射。

## 技术栈

- **前端：** 原生 HTML/CSS/JavaScript（无框架、无构建步骤、无运行时依赖）
- **数据格式：** `scripts/*.js` 中的全局变量数组（唯一真源）；`csv/` 为反向生成的副本
- **图片处理：** 构建期用 Node.js + `sharp`（`resize.js`）生成缩略图；运行期仅浏览器懒加载
- **工具脚本：** Python 3 + `requests`（`search-spec-url.py`、`tools/*.py`）
- **兼容性：** 现代浏览器（Chrome、Edge、Firefox、Safari）

> `package.json` 中声明的 `xlsx`、`iconv-lite` 目前没有任何脚本引用，属于历史遗留依赖。
